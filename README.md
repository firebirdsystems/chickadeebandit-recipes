# Recipes

A [Chickadee Bandit](https://chickadeebandit.com/app-library/recipes) app.

A household recipe book with ingredients, steps, categories, ratings, and difficulty. Add any recipe's ingredients directly to your grocery list.

## Features

- Ingredients, steps, categories, ratings, and difficulty per recipe.
- Add any recipe's ingredients to the shared Grocery List in one tap.
- Family Meals plans the week from this recipe book.
- Private to your household; nothing is published or shared outside it.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-recipes/releases/latest/download/bundle.json
```
